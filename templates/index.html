PROJECT DOCUMENTATION

About this project

Machine Learning-Based Prediction of Timing Violations in VLSI Circuits

Problem statement

Develop a supervised machine learning system that predicts whether a VLSI circuit path has a timing violation using circuit and timing parameters.

Project objectives

  • Prepare and explore circuit timing data.
  • Train and compare multiple classification algorithms.
  • Evaluate with accuracy, precision, recall, F1-score and confusion matrix.
  • Identify parameters associated with timing violations.

Research / demo disclaimer

The project brief describes a 10,000-row dataset. No original dataset or trained model was supplied with the brief, so this runnable package uses a deterministic synthetic dataset for demonstration. Replace it with your authorised project CSV before reporting final results.
